# scoop-apps

[![Tests](https://github.com/soncms/scoop-apps/actions/workflows/ci.yml/badge.svg)](https://github.com/soncms/scoop-apps/actions/workflows/ci.yml)
[![Excavator](https://github.com/soncms/scoop-apps/actions/workflows/excavator.yml/badge.svg)](https://github.com/soncms/scoop-apps/actions/workflows/excavator.yml)

Personal [Scoop](https://scoop.sh) bucket for portable Windows apps and utilities.

## Usage

Add this bucket to Scoop:

```pwsh
scoop bucket add soncms https://github.com/soncms/scoop-apps
```

Install an app:

```pwsh
scoop install soncms/<app-name>
```
